# 길산파이프 랜딩페이지

충남 논산의 길산파이프를 조사해 만든 독립 제작 디자인 시안입니다. 공식 운영 사이트와 무관하며 페이지 하단에 시안임을 표시합니다.

## 모션 v2 업데이트

- 입체 파이프 부유 그래픽과 궤도선, 줄 단위 제목 등장.
- 데스크톱 스크롤에 연결된 소재 → 원형 → 각형 형상 모핑. 모바일에서는 짧은 1회 전개 후 정착하며 장면 버튼으로 선택할 수 있습니다.
- 공장 사진의 4분할 재결합, 제품 선택의 스캔 라인, 버튼과 푸터 글자 반응.
- 모션 일시정지/재생, 시스템 모션 감소 설정, 화면 밖/백그라운드 처리.
- 큰 제목은 공식 로고의 명조 인상에 맞춘 Hahmlet, 본문은 Pretendard. 공식 로고의 원래 폰트를 식별했다고 주장하지 않습니다.

## 바로 실행

- 이 PC에서 `미리보기.cmd`를 더블클릭하세요. Node.js가 필요합니다. 이미 실행 중인 같은 미리보기는 재사용합니다.
- 주소: http://127.0.0.1:4177
- 터미널 실행: 이 폴더에서 `node server.cjs`
- `index.html`을 직접 열어도 페이지를 볼 수 있습니다. 파일 URL의 클립보드 제한 시 직접 복사할 내용을 제공합니다.
- 별도의 패키지 설치나 빌드는 필요 없습니다. 사진·폰트가 로컬에 포함돼 있습니다.

## 구현된 기능

기업소개 → 제품 4개 탭 → 생산시설 및 KS 인증 → 주요 연혁 → 제품 상담 및 위치 안내 순서로 구성했습니다. 제품 탭은 키보드 화살표와 Home/End 키로 이동할 수 있습니다.

상담 창에서 선택한 제품, 강종, 규격, 수량, 요청 사항을 정리해 복사할 수 있습니다. 자동 복사가 차단되면 선택 가능한 원문을 제공합니다. 전화 링크는 `041-732-9994`를 사용합니다. 작성 내용은 전송하거나 저장하지 않으며 문의가 접수됐다고 표시하지 않습니다.

모바일 메뉴, Esc 닫기, 상담 창 닫은 뒤 초점 복원, 주소 복사, 모션 감소 설정을 지원합니다.

## 디자인

공식 로고의 레드를 네이비·실버와 조합했습니다. 실제 공장 전경으로 첫 화면을 구성하고, 제품군은 선택 목록과 사진·설명을 연결해 탐색합니다. Hahmlet·Pretendard·Inter는 이번 시안에서 선택한 서체이며 브랜드 지정 폰트로 주장하지 않습니다.

## 소스와 배포

- 빌드: `npm run build` → `dist/`
- 로컬 실행: `npm start`
- Cloudflare 설정: `DEPLOYMENT.md`
- 자산과 라이선스: `assets/ASSET-SOURCES.md`
- 내부 조사와 아래 검수 자료는 로컬에만 보관하며 GitHub 및 공개 배포물에서 제외합니다.

## 로컬 검수 자료

- `docs/references.md`: 사업 정보의 근거와 레퍼런스 → 반영 위치
- `docs/verification.md`: 실제 브라우저 검수 결과와 남은 사항
- `assets/ASSET-SOURCES.md`: 사진·로고·폰트 출처와 사용 상태
- `output/playwright/v2-desktop.png`: PC 첫 화면
- `output/playwright/v2-desktop-full.png`: PC 전체 페이지
- `output/playwright/v2-mobile.png`: 모바일 첫 화면

## 공개 전 남은 사항

공식 사진과 로고의 공개 사용 권한, 회사의 최종 문구·연락처·제품 정보 승인을 확인해야 합니다. 사진의 촬영 시점과 현재 재고·납기·견적은 확인하지 않았습니다. 온라인 접수 서버는 연결하지 않았습니다. 실제 휴대전화의 통화 앱 실행과 실물 기기 검증은 하지 않았습니다.

공개 배포물은 `build.cjs`의 허용 목록으로 생성합니다. 정적 사이트 파일은 `index.html`, `styles.css`, `motion.css`, `app.js`, `motion.js`, `assets/`입니다. 내부 문서·검수 캡처·서버·실행 도우미는 공개 배포 대상에서 제외하세요. 현재 검색엔진 제외용 `noindex, nofollow`가 설정되어 있습니다.
